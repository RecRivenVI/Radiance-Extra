# 安装与适用范围

适用于 Minecraft 1.21.1 NeoForge。需要同时安装 Radiance；Extra 负责已迁移的 Veil、Sable、Create／Flywheel、Voxy、Simulated 等适配，不代表这些模组所有功能均已接管。

只有安装了对应来源时才加载该适配。Ponder 保持默认光栅语义，不恢复 Ponder PT。

End Sea 遮罩与结构图解的区段缓存会在内容离开绘制集合时正常释放并按需重建。遮罩投影参数与天空／远景淡出由配套本体提供，需同步更新 Radiance；动态位移和薄层外观仍待人工验收，不作为缓存崩溃修复的通过结论。

当前配套候选使用新的公共场景接口，需与同一批次 Radiance 一起更新。Sable 按来源事件维护结构、区段及方块实体成员，移动结构更新共同空间；Flywheel 子实例继承父空间运动，受光由世界路径追踪计算。几何、动画、外观与更新范围保持原规则，不保证所有场景获得相同帧率收益，自动回归不能替代人工观察。

平台区段代际失效后，Sable 取消旧交接并重新登记仍存在的成员。来源卸载、共享交接取消及视距切换时，保留内容依照各自的实际寿命退休；本体与 Extra 必须配套更新，连续动态画面仍需验收。

普通结构区段成员和体积刷新逐段更新，不要求整个结构重建完成后一起出现；实际装拆、分离、合并和表示切换继续共同交接。主世界与独立结构在相近距离内轮流推进区段加载，具体连续加载效果仍需验收。

Voxy 新版远景适配需与本次 Radiance 配套使用；含水方块的流体更新标志不会让方块本体错误使用群系颜色，树叶等常量染色与实际群系染色分别保留。颜色、近远景接缝、水体及动态观感仍待验收，不保证所有场景或长期运行均已验证。

## 已迁入的范围

Sable 的标准烘焙单方块共享局部网格，移动与旋转只改变父空间；无法确认稳定的模型继续实时求值。单方块／多区段切换、拆分、合并及返回主世界共用发布门槛；区段、Flywheel 替代实例和普通方块实体绘制准备完成后再切换。合并按来源胶水的真实接收方等待 sublevel，而非统一等待主世界。需要当前配套本体；实际动态画面由用户验收。

世界材质候选保留 End Sea 的 48 张半格薄层、原纹理和遮罩软边，并让它参与路径追踪、反射、折射及照明。sublevel 的区块表面在海面以下逐渐染成灰紫色，保留纹理和透明度；移动或倾斜不需要重编译结构。须与同批次本体一起更新，本轮动态画面仍待人工验收。

Create／Flywheel／Catnip／Ponder 默认绘制、Sable 子世界、Simulated 与航空学相关表面／线／图解、Veil 已支持的状态与程序、Voxy 指定构建的远景后端由本仓库承担来源适配。迁移不意味着这些模组的所有效果已经支持，也不恢复 Ponder PT 或任意 OpenGL 程序。

不安装对应目标时不加载其适配器；不安装 Extra 时本体仍可独立渲染原版与标准入口。设置里的“绘制接管状态”会分别列出已安装目标、实际注册与当前窗口的真实绘制记录，缺席和未遇到不是通过。

## Flywheel 与缓存模型

最新配套在普通区段更新时继续复用未改变水晶的模型与颜色场，真实形状变化和移除照常更新。End Sea 的远坐标遮罩使用更高精度原点；两项调整需要配套的本体，不能只替换其中一份。

Sable 首次加载时，没有旧地形需要替换的结构会逐段出现，不会因为包围盒覆盖其他建筑而一同延迟它们。真实装拆、分离和合并继续保留地形与模型交接；结构运动只调整空间与仍在排队的加载优先级。

Radiance 生效时 Flywheel 的可用模式固定为 `radiance_extra:instancing`，旧模式偏好在读取时转到该模式。Radiance 未生效时保持 Flywheel 原来的选择规则。

齿轮、轴等稳定模型由 Flywheel 自己的模型身份复用；旋转、移动、颜色、纹理滚动与可见性更新实例参数。Catnip 缓存模型使用同一公共局部模型能力；弹簧、绳索和其他真实变化的程序化几何仍按来源需要生成，不冻结动画。Ponder 和物品光栅预览保持原路径及照明。自动回归不代表所有第三方绘制都已完成接管，也不代替动态画面验收。

直接 PT 输出与已知 Sable 照明包装使用相同的 Catnip 材质规则，保留贴图本色、染色、透明度、动画和独立发光。安山门、黄铜门默认侧面贴图的上下色差，以及安山门折叠模型切换的 UV 差异保持不变；这些颜色差异不等于额外受光。

## Veil 绘制与资源

Veil 仍按实际绘制状态决定沿用原版解释、完整捕获或执行已适配的界面／离屏绘制；安装 Veil 不会整体关闭原版接管。普通世界不增加通用光栅后渲染，自定义程序也不保证支持。

已支持的程序保留来源混合模式、独立纹理和 uniform block 绑定。资源重载和动态缓冲变体切换使用当前程序版本；CPU 布局跟随具体编译对象释放，原生编号相同或被重新使用也不会移除其他对象的数据。无法读取的纯 OpenGL block 或缺少必需数据的绘制会被跳过，不以旧数据代替，也不吞掉分配失败或设备丢失。

稳定全屏三角形只上传一次；uniform block 按来源变化通知序列化，再为每次绘制复制独立的 uniform 数据。持久缓冲只复用已经结束在途使用的旧版本，尺寸或用途不匹配时重新分配。这些机制减少重复工作，不代表已证明某个场景的帧率收益；具体图解、屏幕效果与重载后的外观仍需体验验收。

## Levitite 浮空水晶

航空学 1.3.2 的 Levitite 和珠光 Levitite 使用世界路径追踪照明。主体保留细微的颜色闪烁，移动结构上的两层偏色重影保留噪声形变；运动、重力和材料参数共同决定强度。重影是非折射半透明表面，在反射和玻璃后的画面中同样存在，不是屏幕叠加层，也不被当作光源。

主体的细分颜色与几何分开处理；静止的普通方块不准备移动重影。移动重影在显卡上生成，仍保留原有形变、透明度和接触淡化。大量持续形变的表面仍需更新光追加速结构，不能视为无成本的静态模型。

Ponder 教程遵循航空学主动关闭这套特效的行为，普通模型与教程动画仍正常显示。

交界处采用空间距离淡化，取代只在主视图成立的屏幕深度效果；它与原光栅画面不保证逐像素一致。当前支持主世界与移动结构；航空学的两种水晶即使只有单方块，也按来源标签走区段路径。资源重载后重新建立配套资源；动态外观仍需实际体验验收。
