# 更新日志

适用于 Minecraft 1.21.1 NeoForge。

## [未发布]

### 修复

- 精确登记 Ponder 的原版 RenderType 工厂调用入口，避免普通材质状态整体退回完整捕获；自定义图层及 Veil 实际附加状态继续分别判断。
- Sable 普通区段成员与体积刷新独立发布，不再因此创建整组交接；真正装配、拆分、合并、拆解及单方块表示切换仍保留关联版本的共同发布。
- 未改变的 Levitite 内容继续复用模型与颜色场，不因普通区段发布版本变化反复重建；真实内容更新仍安全替换，删除和重载正常失效。
- End Sea 使用配套本体的高精度水平原点与纹理投影，修正远坐标下遮罩及薄层采样的提前舍入；需与 API 16 本体一起更新。
- Levitite 主体复用原始平面几何，细分颜色场及移动重影由 GPU 计算；不再逐帧在 Java 展开噪声和曲面。两层重影共用主体来源网格并按需创建，接触淡化复用局部形状快照，附近方块或覆盖范围改变时才更新。
- 修正 Levitite 在移动结构内部远坐标下的精度丢失，避免偏色重影退化、缺面或偏移，并保持主体噪声颜色使用正确的局部位置。
- 航空学 Levitite 主体使用持久世界模型和动态颜色场；两层偏色重影按来源速度、角速度、重力与材料参数细分形变，作为非折射半透明世界几何参与反射和折射。空间交界淡化替代屏幕深度渐隐，不执行旧光照、屏幕雾或任意 Veil 世界程序；需配套本体。
- Sable 初次加载在没有待替换旧地形时逐段显示，不再将包围盒内全部主世界区段一起扣住；装配、拆解、分离、合并及实际 BER／Flywheel 所有者继续保留共同交接。
- Sable 在平台区段代际失效后取消旧交接并重新收集有效来源，配合本体按持有者管理取消、共享成员、空间退休和槽位重定位；需要同批次本体。
- 柔性弹簧在曲线生成前检查端点及相对空间输入，稳定连接保留当前局部几何，受力染色和 UV 伸缩独立更新；真实形变替换当前版本，界面预览保留原路径。
- Voxy 按来源、相机和有效近景覆盖变化更新 LoD 选择，暂停未使用节点的排队生产；保留已发布父节点、真实来源发光、动态水面和重载寿命。
- 区分 Voxy 模型自身的群系染色与含水方块继承的流体更新标志，避免将白色常量误当颜色表索引而崩溃；保留常量染色、真实群系染色和逐面染色范围。
- Veil 程序重载先启用新版本再释放旧版本，切换已缓存变体同步更新解释状态；CPU 布局按编译对象独立归属，原生编号重用不交叉覆盖，保留来源 block 和混合模式。
- Veil 无法消费的 OpenGL block 在绘制提交前跳过；storage block 广播不再干扰无关程序，实际声明不支持的 storage block 在编译阶段拒绝。
- 重做远景代理的来源材质、染色、更新和物理光源接入，修正静态区块与远景共存时的光源索引错误；需配套更新本体与 Extra，实际外观仍待验收。
- Flywheel 正式使用 radiance_extra:instancing，Radiance 生效时配置、后端切换和重载遵守同一模式；模型首次需要时上传，实例仅由变化队列处理，保留来源动画和破坏覆盖。
- Catnip 不可变缓存模型通过公共局部模板提交，姿态、颜色、UV 和 overlay 分开更新；世界路径移除固定方向光与无效受光采样，界面预览保留原始照明。
- 普通方块实体与混合 Visual／BER 内容加入 Sable 的共同交接门槛，保留字体页、旧批次与模型的合法寿命；本体与 Extra 需要同步更新。
- 合并等待实际接收 sublevel，拆分关系保留到子结构收到数据；Flywheel 依方块实体的真实所有者保留旧实例及空间，替代模型准备好后与区段共同发布，重载与卸载释放交接。
- Sable 稳定单方块改用共享局部模型和独立持久实例，结构姿态不再触发顶点重建；自定义动态模型保留实时求值。
- Sable 建立、拆分、回到主世界及单方块／多区段切换使用当前替代版本的共同发布门槛，资源重载和卸载分别清理。
- Voxy 通过公共成像距离合同声明远景范围，不再改写雾色或浸没／状态视野效果。
- 修正 End Sea 遮罩与结构图解移除区段缓存时读取失效映射条目的崩溃；先保存资源再退休，网格上传保持明确所有权，清理失败继续传播并保留原始绘制异常。

### 变更

- 统一已知 Sable 照明包装与直接 PT 输出的 Catnip 处理，直接输出不遍历来源适配器；保留贴图本色、UV、透明度及光栅预览照明。这是包装合同补强，不改变门侧面固有色差。
- Voxy 通过公共成像距离合同声明远景范围，不再改写雾色或浸没／状态视野效果；本轮需使用 API 9 的配套 Radiance。

### 新增

- End Sea 使用来源末地传送门纹理、48 张水平薄层与半格间距，通过公共材质接入世界 PT；深度及五轮扩散强度遮罩完成后收集，主视线和光源采样共用衰减。
- End Sea 离屏遮罩复用来源区段的原始光栅网格，独立维护其发布版本和资源重载寿命，不使用世界 PT 归一化后的属性或失效缓冲。
- Sable 区块表面保留海面以下三十格的灰紫渐变染色，按当前世界姿态求值，不重编译移动结构，不新增自发光或光栅照明。
- Veil uniform block 复用直接内存，按来源 dirty／尺寸变化序列化并复制到每次绘制独立的数据；释放时清理 CPU 缓存。固定全屏三角形使用持久缓冲，不再逐次生成和上传。
- Sable 内含、跟随和乘坐的原版实体共用本体来源解释，空间姿态与成员状态分别维护；睡眠与名称姿态保留来源回调，世界不再用向上法线模拟固定方向光，预览不变。固定版本修改按实际字节登记；Veil 未知追加状态仍执行完整来源路径。Flywheel 世界实例不再提交无效光栅 lightmap，材质颜色、覆盖和物理发光保持独立。
- 使用配套公共场景接口维护 Sable 成员与区段，父空间运动与内容更新分离；Flywheel 实例共享父空间变换和照明，保留来源动画与资源生命周期。
- 解释来源图层的覆盖与离屏语义；Voxy 投影纹理和 Sable 持久缓冲使用配套平台的所有权接口，保留原有绘制与退休行为。
- 从本体迁入既有第三方适配与探针，使用固定公共 API 编译；原生执行仍由 Radiance 本体提供，不内嵌另一份渲染器。
- 将 Flywheel 实例格式和 Voxy 紧凑格式解释保留在来源适配，提交通用实例／LOD 合同；保留原有动画、材质、近远景交接和资源寿命。
- 从 Radiance 分离既有第三方适配，通过公共接入平台提供实际来源、生命周期与渲染请求。
