# Radiance Extra

适用于 Minecraft 1.21.1 NeoForge，为 Radiance 提供第三方绘制来源的专项适配。本模组依赖 Radiance，不包含独立渲染器。

## Target

| Target | 加载器版本 | Java |
| --- | --- | --- |
| `1.21.1-neoforge` | 21.1.259 | 21 |

## 快速开始

同时安装 Radiance 与 Radiance Extra；只安装与当前已验证版本相符的第三方模组。
